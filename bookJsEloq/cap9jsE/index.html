JAVACRIPT CAP9

EXPRESIONES REGULARES

Son una forma describir patrones en datos de cadena/

Una exprecion regular es un objeto y puede ser construido con el constructor RegExp() o escrito como un patron entre caracteres de barra diaginal (/).

let re1 =  new RegExp("abc")
let re2 = /abc/

Algunos caracteres como el signo de - o + tiene significados especiales en expresiones regulares y deben ser presedidos de una barra invertida si se desea representar el propio caracter

let aPlus = /A\+/

PRUEBAS DE COINCIDENCIA

Los objetos de patrones regulares tienen varios metodos. El mas simple es test. Si le pasa una cadena devolvera un Booleano indicando si la cadena tiene coincidencia con el patron de la expresion.

console.log(/abc/.test("abc"))

Si abc aparece en cualquier parte de la cadena contra la cual estamos probando (no solo al principio), test devolverá true.

CONJUNTO DE CARACTERES

En una expresion regular, poner un conjunto de caracteres entre corchetes hace que esa parte de la expresion coincida con cualquier con cualquiera de los caracteres entre los corchetes.

console.log(/[0123456789]/.test("in 1992")) // → true
console.log(/[0-9]/.test("in 1992")) // → true

Dentro de corchetes, un guion (-) entre dos caracteres se puede usarpara indicar un rango de caracteres.

Varios grupos comunes tiene su propias abreviaturas incorporadas.

\d Cualquier caracter digito.
\w un caracter alfanumerico.
\s Cualquier carácter de espacio en blanco (espacio tabulación, nueva línea, y similares).
\D Un caracter que no es un digito.
\W Un caracter no alfa numerico.
\S Un caracter que no es de espacio en blanco.
. Cualquier caracter excepto nueva linea.

Podrias hacer coicidir un formato de fecha y hora 01-20-2003 15:20 con la siguiente expresion.

let dateTime = /\d\d-\d\d-\d\d\d\d/
console.log(dateTime.test("1-2-2023")) // → false
console.log(dateTime.test("01-02-2023")) // → true

Para invertir un conjunto de caracteres, es decir, expresar que deseas hacer coincidir cualquier carácter excepto los que están en el conjunto, puedes escribir un carácter circunflejo ^

let nonBinary = /[^01]/
console.log(nonBinary.test("1100100010100110")) // → false
console.log(nonBinary.test("0111010112101001")) // → true

Lo que el circunflejo pregunta "hay algun valor que no coicida con esto, este caso 0 y 1" si se comple devuelve un false.

REPETIR PARTES DE UN PATRON

Que tal si queremos hacer coincidir una secuencia de uno o mas diguitos...

Cuando se coloca el signo + en una expresion regular significa que el elemento puede repetirse mas de una vez. Asi ./\d/ hace conicidir uno o mas caracteres de digitos.

console.log(/'\d+'/.test("'123'"))  // → true
console.log(/'\d+'/.test("''"))  // → false
console.log(/'\d*'/.test("'123'")) // → true
console.log(/'\d*'/.test("''")) // → true

El * permita que el patron coicida cero veces. Algo con un asterisco despues nunca impide que el patron coincida.

Un signo de interogacion ? permite que el caracter anterior sea opcional, lo que significa que puede ocurrir cero veces o una vez.

let neighbor = /neighbou?r/;
console.log(neighbor.test("neighbour")) // → true
console.log(neighbor.test("neighbor")) // → true

Para indica que un patron debe ocurrir un numero preciso de veces, utiliza llaves. Colocar {4} despues de un elemento, requiere que ocurra exactamente cuatro veces.

Tambien es posible indicar un rago de esta manera {2,4} significa que el elemento debe ocurrir almenos dos veces y maximo cuatro

let dateTime = /\d{1,2}-\d{1,2}-\d{4}/
console.log(dateTime.test("1-2-2001")) // → true
console.log(dateTime.test("01-02-2001") // → true

Tambien puedes especificar rango abierto omitiendo el numero despues de la coma. Asi, {5,} significa cinco o mas veces.

AGRUPACION DE SUBEXPRESIONES

Para usar un operador como * o + en mas de un elemento a la vez, debes utilizar parentisis. Una parte que este dentro de un parentsis cuenta como un solo elemento.

let cartoonCrying = /boo+(hoo+)+/i;
console.log(cartoonCrying.test("Boohoooohoohooo")); // → true

El primer y segundo caracter + se aplicar a boo y hoo. El tercer + se aplica a todo el grupo (hoo+) haciendo coicidir una o mas secuencias como esta. La i al final indica que todos los valores se concideran en minusculas

COINCIDENCIAS Y GRUPOS

El metodo test es la forma mas simple de hacer coincidir una expresion regular. Solo te indica si hubo coicidencia y nada mas.

Las expreciones regulares tambien cuentan con el metodo exec que devuelve un null si no encuentra coincidencia y devolvera un objeto con la informacion sobre la coicidencia en caso contrario.

let coincidencia = /\d+/.exec("uno dos 100")
console.log(coincidencia); // → [ '100', index: 8, input: uno dos 100', groups: undefined ]

El objeto devuelto por exec tiene un propiedad index que nos dice donde en la cadena comenzo la coicidencia.

PATRONES DE ELECCION

Para saber si un texto tiene no solo letras sino palabras podriamos utilizar el caracter de barra vertical (|) denota una eleccion entre el patron a su izquierda o patron asu derecha.

let animalCount = /\d+ (pollo|vaca|toro)s?/
console.log(animalCount.test("12 vacas")) // → true
console.log(animalCount.test("1 toro")) // → true

EL METODO REPLACE

El primer argumento tambien puede ser una expresion regular, en cuyo caso se remplaza la primera coincidencia de la expresion regular

console.log("Borobudur".replace(/[ou]/, "a")) // → Barobudur

Cuando se agrega una opcion g (para global) despues de la expresion regular, todas las coincidencias en la cadena seran resmplazadas, no solo la primera.

console.log("Borobudur".replace(/[ou]/g, "a"))// → Barabadar

El verdadero poder de usar expresiones regulares con replace proviene del hecho de que podemos hacer referencia a grupos coincidentes en la cadena de reemplazo

console.log("Liskov, Barbara\nMcCarthy, John\nMilner, Robin".replace(/(\p{L}+), (\p{L}+)/gu, "$2 $1"));
// → Barbara Liskov
// John McCarthy
// Robin Milner

Los $1 y $2 en la cadena de reemplazo se refieren a los grupos entre paréntesis en el patrón. $1 es reemplazado por el texto que coincidió con el primer grupo,$2 por el segundo, y así sucesivamente, hasta $9. Toda la coincidencia se puede referenciar con $&.

RESUMEN

/abc/ Una secuencia de caracteres.
/[abc]/ Cualquier carácter de un conjunto de caracteres.
/[^abc]/ Cualquier carácter que no esté en un conjunto de caracteres.
/[0-9]/ Cualquier carácter en un rango de caracteres.
/x+/ Una o más ocurrencias del patrón x.
/x+?/ Una o más ocurrencias, perezoso.
/x*/ Cero o más ocurrencias.
/x?/ Cero o una ocurrencia.
/x{2,4}/ Dos a cuatro ocurrencias.
/(abc)/ Un grupo.
/a|b|c/ Cualquiera de varias combinaciones de patrones.
/\d/ Cualquier carácter de dígito.
/\w/ Un carácter alfanumérico (“carácter de palabra”).
/\s/ Cualquier carácter de espacio en blanco.
/./ Cualquier carácter excepto saltos de línea.
/\p{L}/u Cualquier carácter de letra.
/^/ Inicio de entrada.
/$/ Fin de entrada.
/(?=a)/ Una prueba de vistazo hacia adelante.
