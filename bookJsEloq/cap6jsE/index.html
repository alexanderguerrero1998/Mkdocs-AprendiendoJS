TIPOS DE DATOS ABSTRACTOS

Cada tipo de datos abstracto tiene una interfaz, que es una coleccion de operaciones que el codigo externo puede utilizar en el.

Un tipo de dato abstracto, o clase de objeto es un subprograma que puede contener codigo arbitrariamente complicado, pero que exponer un conjunto de metodos y propiedades que se supone que las personas que trabajan con el deben usar.

METODOS DE OBJETOS

Un metodo es una propiedad que tienen como valor una funcion. let persona = {
nombre : "Alex",
saludar : function() {console.log("Hola!")
}}; nombre → propiedad con valor de texto saludar → propiedad con valor de función → cuando la llamas

Cuando una funcion es asignada como propiedad de un objeto — y esta es invocada por el objeto que la contiene — la vinculacion this definida en su cuerpo apunta directamente al objeto que la llamo.

function speak (line) {
  console.log(`El conejo '${this.type }' dice '${line}'`)
}

let conejoBlanco= { type:"blanco", speak }; //← (Aqui esta la funcion speak definida como "Property Shorthand" es lo mismo que, speak:speak)

conejoBlanco.speak("Oh, mi pelaje y mis bigotes") //← (Aqui se INVOCA la funcion)
// → El conejo blanco dice 'Oh, mi pelaje y mis bigotes'

Dado que cada funcion tiene su propio this, no puedes referenciar al this del ambito envolvente en una funcion regular definida con la palabra clave function. Las funciones flecha son diferentes —no vinculan su propio this pero pueden ver la vinculación this del ámbito que las rodea.

let buscador = {
  find(array) {
    return array.some(v => v == this.value)
    },
    value: 5
};
console.log(buscador.find([4,5]));
// → true

Se puede ver como this.value definida en funcion (find) hace referencia a la propiedad value del objeto que la contiene. Tambien se puede ver que no la funcion no esta asignada a una propiedad, quiere decir que tiene abreviatura "Method Definition Shorthand", esto es lo mismo que decir, 

find : function(array){
        return array.some(v => v == this.value)
        }

PROTOTIPOS

Los objetos simples creados con notacion { } estan ligados a un objeto prototipo llamado Object.prototype (que no tiene prototipo.). Las funciones se derivan de Function.prototype, y los arreglos se derivan de Array.prototype.

Puedes utulizar Object.create para crear un objeto con un prototipo especifico.

let protoAguila = {
  speak( line ) {
    console.log( `Soy una aguila '${ this.nombre }' y '${ line }'`)
  }
}
let aguilaCalva = Object.create(protoAguila);
conejo.nombre = "calva"
conejo.speak("bonita")
// → Soy una aguila calva y bonita

let aguilaNegra = Object.create(protoAguila) //→ ( Crea otro objeto con el mismo prototipo ( protoAguila ) )

El aguila "proto" actua como contenedor para las propiedades que son compartidas por todos las aguilas. Un objeto de aguila individual, contiene propiedades que se aplican a el mismo, y deriva propiedades compartidas de su prototipo.

console.log(Object.getPrototypeOf(aguilaCalva) == protoAguila) 
// → true (Quiere decir que el prototipo de aguilaCalva es protoAguila)

CLASES

Una clase define la forma de un tipo de objeto, lo metodos y las propiedades que tiene. A dicho objeto se lo considera una instancia de clase.

class Particle 
{
    speed = 0;
    constructor ( position ) {
        this.position = position;
    }
}
let subParticula = new Particle(7)

Al igual que function, class se puede utilizar tanto en declaraciones como en expresiones.

let object = new class { 
    getWord() { return "hello" } 
}
console.log(object.getWord()) // → hello

PROPIEDADES PRIVADAS

Para declarar un metodo privado coloca el signo # delante de su nombre. Estos solo puede ser llamados dentro de la clase que los define.

class SecretiveObject {
  #getSecret() { return "Me comí todas las ciruelas" }
  interrogate() {
    let deboDecirlo = this.#getSecret();
    return "nunca";
  }
}

Para crear una propiedad privada, primero debe declararse en la definicion de la clase para estar disponible en absoluto.

class RandomSource {
  #max;
  constructor(max){this.#max = max}
  getNumber(){return Math.floor(Math.random()*this.#max);
  }
}

MAPAS

Los mapas son estructuras que admiten claves y valores semejantes a un objeto. Pero adiferencias de estos los objetos no admiten objetos como claves, afortunadamente la clase Map esta escrita para este proposito.

let ages = new Map()
ages.set("Boris", 39)
ages.set("Liang", 22)
ages.set("Julia", 62)
console.log(`Julia tiene ${ ages.get("Julia") }`) // → Julia tiene 62
console.log("¿Se conoce la edad de Jack?", ages.has("Jack"))// → ¿Se conoce la edad de Jack? false

Los metodos set, get y has forman parte del objeto Map
