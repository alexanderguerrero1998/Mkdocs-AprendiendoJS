MODO ESTRICTO

En resumen, colocar use strict al principio de tu programa rara vez duele y podría ayudarte a identificar un problema.

EXEPCIONES

Cuando una funcion no puede ejecutar normalmente surgen las excepciones, son un mecanismo que el codigo que tiene problemas lanze una excepcion.

function promptDirection() {
    let result = "Lefh";
    if (result.toLowerCase() == "left") return "L";
    throw new Error("Dirección inválida: " + result);
}
function look() {
    if (promptDirection() == "L") 
        return "una casa";

} try {
    console.log("Ves", look());
} catch (error) {
    console.log("Algo salió mal: " + error.stack);
}
console.log("El programa sigue corriendo...")
// → Algo salió mal: Error: Dirección inválida: Lefh
// → El programa sigue corriendo...

La palabra throw se utiliza para lanzar una excepcion. La captura de una excepcion se realiza envolviendo un trozo de codigo en el bloque try, seguido de la palabra catch. Cuando try detecta una excepcion, se evalua el bloque catch con el nombre entre parentesis vinculado a la excepcion.

Se utiliza el constructor Error para crear el valor de excepcion, este constructor crea un objeto con la propiedad message. Las Instancias de Error almacenan la informacion sobre la pila de llamadas cuando se crea la excepcion. Esta informacion se alamcena el la propiedad stack
