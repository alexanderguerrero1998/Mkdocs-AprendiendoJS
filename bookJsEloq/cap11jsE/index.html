ASINCRONIA

La asincronía es un comportamiento natural del entorno de ejecucion. Por lo tanto, la asincronia no es algo que tu puedas controlar, si no mas bien, es algo con lo que tienes que aprender a lidear, para ello existen tres formas: (callbacks, promesas y async/await) cada una mas elegante que la otra, en un intento de que el programa se vea lo mas "natural y normal" posible,

Entoces este comportamiento(asincronia) nos dice: que un programa puede seguir ejecutandose sin la necesidad de esperar a que una tarea lenta termine. Esto quiere decir que, cuando ciertas operaciones tardan, el sistema las delega para no bloquear el hilo, luego cuando la funcion asincrona termina lo informara por medio de un: callback, una promesa o async-await.

Si una funcion realiza algo que tarda tiempo y no quiere bloquear el hilo de
ejecucion, esta funcion se considera asincrona.

Una funcion asincrona permite iniciar un proceso que tardará en completarse y luego ceder el control inmediatamente, sin bloquear lo demás, para que cuando ese proceso termine pueda avisarle a tu programa (por ejemplo, mediante un callback, una Promise, o await).

Una operacion asincrona simpre necesita una de estas tres cosas:

  • Un callback
  • Un .then()
  • Un await 
// EJM. CALLBACK EN FUNCION ASINCRONA
function imprimir(callback) {
  let frase =  " funcion de callback en una funcion asincrona.."
  setTimeout( ()=> callback(frase),5000)

}
imprimir((texto) => console.log(texto))
console.log("Continuamos....")

// → Continuamos....
 // funcion de callback en una funcion asincrona..

//  ()=> callback(frase) ← Esto pasa la funcion para ajecutarala         
// callback(frase) ← Esto pasa el resultado y no la funcion

PROMESAS

Una promesa es un recibo que representa un valor que aun no puede estar disponible.

Proporciona un metodo then() que permite registrar una funcion que debe ser llamada cuando la accion por la que esta esperando finalice

Cuando la promesa se resuelve, se manda a llamar a las funciones registradas en then()conjuntamente con el valor resuelto. La forma mas sencilla de crear una promesa es llamando a Promise.resolve.

Esta funcion se asegura que el valor que le proporcionas este envuleto en una promesa

let numero = Promise.resolve(15)`
`numero.then(x=> console.log(x)) //→ 15 (Aqui la promesa ya esta resuelta)

Para crear un promesa que no se resuelva inmediatamente se usa Promise como constructor. Donde el constructor espera una funcion como argumento. Estructura Interna → new Promise(executor) donde resolve y reject son los parametros de esta funcion interna y ademas son funciones, es decir, que resolve y reject son parametros que reciben funciones, que se las da internamente javascript. Ejm.

// EJM.1 USANDO PROMESA 
let a = new Promise(resolve => resolve("Hola")) // ← Este (RESOLVE) es el parametro que recibe una funcion
a.then(console.log) // → Hola`

// EJM.2  PROMESA EN FUNCION
function getresult() {
return new Promise(resolve => resolve("Hola"))
}
getresult().then(console.log) // → Hola

La promesa cambia de estado cuando ejecutas resolve() o reject(), no cuando “recibe un valor”

FUNCIONES ASINCRONICAS

Una palabra async tiene la palabra reservada async antes de la palabra function. Cuando se llama a una funcion de esta manera se devuelve una promesa.

Dentro de una funcion async, la palabra await puede colocarse delante de expresion para esperar a que una promesa se resuelva y luego continuar con la ejecucion de la funcion. Si la promesa es rechazada se genera una excepcion en el punto del await

Una funcion asi ya no se ejecuta como una funcion regular de JavaScript, de principio afin, en su lugar puede estar congelada en cualquier punto que tenga un await y puede continuar mas tarde.

Una funcion que tenga async siempre devuelve una promesa aunque no lo veas.Ejmp.

async function saludo() {
  return "Hola";
}
console.log(saludo()) // → Promise {'Hola'}

await se ocupa unicamente cuando vas a recibir una promesa. Si no hay promesa, no hay nada que recibir.

await siempre necesita una funcion async que la contenga

function sumar(a,b) {
  return new Promise(resolve => setTimeout(() => resolve(a*b),5000))
}

async function resultado(x,y) {
  let res =  "Somos la respuesta de await!" + await sumar(x,y)
  console.log(res)
}
resultado(1,2)
console.log("Seguimos trabajando hasta que se resuelva...")
// → Seguimos trabajando hasta que se resuelva...
// Somos la respuesta de await!2
