CONTROLADORES DE EVENTOS

Son funciones que permiten manejar eventos especificos.

addEventListener es una de estas funciones, es decir, es un metodo del objeto global windows que permite registrar como primer argumento un evento y como segundo argumento una funcion que se llamara cada vez que ocurra ese evento. 

  <p>Haz clik para activar el manejador<p>    
  <script>
      window.addEventListener("click", ()=> console.log("Llamaste ?"))
  </script>
  // → Llamaste ?

EVENTOS Y NODOS DOM

Cada controlador de eventos se registra en un contexto, en el caso anterior el metodo addEventListener se registro en el contexto de toda la ventana del navegador.

  // Este ejemplo sirve para demostrar que los
  // callback solo se llaman cuando el evento 
  // ocurre dentro del contexto del objeto 
  // donde fue registrado

  // Es decir que si hago clic en otra parte de la pantalla
  // que no sea el boton no ejecutara nada porque 
  // el evento y su callback esta registrados en el
  // contexto del botton, no en toda la pantalla como en el
  // ejemplo anterior.

  <p>No hay menejador aqui</p>    

  <script>
      let button = document.querySelector("button")
      button.addEventListener("click", ()=> console.log("Boton Click"))
  </script>

Existe una diferencia entre: element.onclick y .addEventListener("click", ...)

En la primera solo puede existir una funcion asignada, si asignas otra remplaza la anterior

  element.onclick = () => console.log("Uno")
  element.onclick = () => console.log("Dos")
  // → Se se ejecuta solo "Dos"

En la segunda puedes agregar multiples funciones la mismo evento, permita mas control (captura, opciones, removeEventListener). Y es la mas moderna y orofesional

element.addEventListener("click", () => console.log("Uno"));
element.addEventListener("click", () => console.log("Dos"));
// Se ejecutan ambos

El metodo removeEventListener tiene los mismo argumetnos que addEventListener y permite remover un manejador.

El mismo elemento que recibe addEventListener debe recibir removeEventListener para anular el manejador.

OBJETOS EN EVENTOS

Las funciones manejadores de eventos (los callback) reciben implicitamente un argumento: que es el objeto del evento (Ejm. el objeto del evento "click"). Este objeto contiene informacion del evento.

  // Si queremos saber cual boton del mouse se presiono 
  // podemos ver la propiedad button del objeto del evento
<button>Haz clic</button>
<script>
    let button = document.querySelector("button")
    button.addEventListener("mousedown", evento =>{
        if (evento.button == 0)
        console.log('Boton Izquierdo')
        if(evento.button == 1)
        console.log('Boton Centro')
        if(evento.button == 2)
        console.log('Boton Derecho')
    })
    // → Boton Izquuiero
    // Boton Derecho
    // Boton Centro
</script>

La informacion almacenada de un objeto de evento, difiere segun el tipo de evento.

ACCIONES PREDETERMINADAS

Cuando estamos en una pagina web normamente si vemos un link podemos clicar y nos llevara a donde este dirigido el enlace o presionar presionar un la tecla hacia abajo para que la pagina se desplace a abajo esto seria lo normal o lo que el usuario esperaria.

En JavaScrip se puede evitar este comportamiento "normal" utilizando el metodo preventDefault

<a href="www.google.com">Haz clic</a>

let enlace = document.querySelector("a")
enlace.addEventListener("click", event => { console.log("Inhabilitado!")
  event.preventDefault()
})

Considera que esto es molesto para el usuario y que hay algunos eventos aparte de este que no funcionaran dependiendo el navegador.

EVENTOS DE TECLADO

Cuando presionas una tecla del teclado el navegador dispara un evento keydown. Cuando se suelta obtiene un evento Keyup

window.addEventListener("keydown", evento =>{
    if(evento.key == "v")
        document.body.style.background = "blue"
} )

window.addEventListener("keyup", evento => {
    if(evento.key == "v")
        document.body.style.background = "red"
})

Los eventos keydown y keyup que vimos anteriormente se activan cuando se presiona o suelta la tecla.

La propiedad key del objeto del evento permite ver sobre que tecla se presiono y genero el evento.

Las teclas modificadoras como SHIFT, CONTROL, ALT tienen las siguientes propiedades shiftKey, ctrlKey, altKey.

EVENTOS DE PUNTERO

Actualmente hay dos formas de señalar cosas en una pantalla: ratones y pantallas tactiles.

CLICS DE RATON

Presionar un boton del raton genera varios eventos. Los eventos mousedown y mouseup se activan cuando se presiona o suelta el boton .

Para obtener informacion precisa sobre el lugar donde ocurrio un evento de raton puede utilizar suspropiedades clientX - clientY - pageX - pageY

Una analogia para comprender estas diferencias es: Imagina que tu página es un edificio enorme. Y tu pantalla es solo la ventana por donde estás mirando.

clientX / clientY

Miden la posición del mouse dentro de la ventana que estás viendo. No importa cuánto hayas hecho scroll. Siempre empieza a contar desde la esquina visible.

Si haces scroll 2000px hacia abajo y haces clic arriba de la pantalla:

clientY = 10

Porque estás a 10px del borde visible.

pageX / pageY

Miden la posición respecto a todo el edificio completo (toda la página). Sí importa cuánto scroll hiciste.

En el mismo caso:

pageY = 2010

Porque estás 2000px abajo + 10px desde arriba visible.

MOVIMIENTO DEL RATON

Cada vez que el puntero del raton se mueve se produce un evento mousemove que sirve para rastrear la posicion del raton
