REDES E INTERNET

Un protocolo es un estilo de comunicacion sobre una red.

El protocolo HTTP(Protocolo de Trasnferencia de Hipertexto) es un protocolo para recuperar recursos nombrados(trozos de informacion, como paginas wen o imagenes). Especifica una solicitud que debe comezar con una linea indicando el nombre del recurso y la version del protocolo que esta intentando usar. GET /index.html HTTP/1.1

Internamente HTTP trata a la red como un flujo donde puedes poner bits y hacer que lleguen al destino correcto en el orden correcto.

El TCP(Protocolo de Control de Trasnmision) es el encargado de que los bits lleguen el el orden y destino correcto. Todos los dispositivos conectados a Internet lo hablan y la mayoria de comunicaciones en internet se construyen sobre el.

Una comunicacion TCP funciona asi: una computadora debe estar escuchando a que otras computadoras comienzen hablar con ella. Para poder escuchar diferentes comunicaciones, al mismo tiempo en una misma maquina, cada oyente debe tener asociado un numero (llamado puerto).

La mayoria de los protocolos especifican que puerto usar de forma predeterminada. Entonces una computadora puede establecer una conexion con una maquina de destino usando el numero de puerto correcto. La computadora que escucha se llama servidor y la computadora que se conecta se llama cliente

LA WEB

El Word wide Web es un conjunto de protocolos y formatos que permiten visitar paginas web en el navegador. La parte Web se refiere al hecho de que estas paginas pueden enlazarce facilmente entre si, conectandose as en una gran malla por la que los usuario pueden moverse. Es decir, que cada pagina web puede tener hipervivulos a otras paginas sin importar donde este alojada la pagina fisicamente.

Para formar parte de la web todo lo que necesitas es conectar una maquina a internet y hacer que escuche en el puerto 80 con el protocolo HTTP para que otras computadoras puedan solicitarle documentos.

Cada docuemento en la web esta nombrado por un localizador de recursos Uniforma(URL)

Elemento Ejemplo Descripción
Protocol http:// Indica el tipo de comunicación (HTTP/HTTPS)
Servidor eloquentjavascript.net Nombre del dominio o servidor donde está la página
Ruta /13_browser.html Ubicación específica del recurso en el servidor

La primera parte nos dice que esta URL utiliza el protocolo http, encontra posicion cifrado seria https//. Luego nos idica desde que servidor estamos solicitando el documento. Por ultimo esta una cadena ed ruta que identifica el documento especifico (recurso).

Las maquinas conectadas tienen una direcion IP que se puede utilizar para enviar mensajes a esa maquina y se algo como 149.210.142.219 o 2001:4860:4860::8888. Esta lista de numeros es dificil de ecordad asi que en su lugar puedes registrar un nombre de dominio para una direccion especifica o un conjunto de direcciones.

HTML Y JAVASCRIPT

Lenguaje de marcado de hiper texto documento utilizando para paginas web.

La etiquete mas importante en este contexto es < script > que permite incluir codigo javascript en un documento.

La etiqueta src obtiene un archivo script(codigo JS)

Puedes cargar modulos ES en el navegador al darle a la etiqueta script un atributo type=module
